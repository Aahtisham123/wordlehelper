# wordlehelp.co

Source for **[wordlehelp.co](https://wordlehelp.co)**: a Wordle Helper (solver) on the homepage, plus Wordle tools, daily hints, an answers archive, programmatic word lists and guides.

The site is plain static HTML generated by a small Node script. There's no framework and no runtime dependencies. All solving runs in the visitor's browser.

## Commands

```bash
npm run build        # generate the site into dist/
npm run serve        # preview dist/ at http://localhost:8080
npm run dev          # build + serve
npm test             # engine tests + full build, link and SEO checks
npm run add-answer -- 2026-10-24 crane "optional one-line clue"
```

Node 18+ is required. `npm install` is only needed to regenerate the word lists (`npm run wordlists`).

## Site structure

| URL | Source | Notes |
|---|---|---|
| `/` | `src/pages/home.mjs` | Wordle Helper tool + ~1,000 words of content + FAQ |
| `/wordle-hint-today/`, `/wordle-answers/` | `src/pages/daily.mjs` | Driven by `data/daily.json` |
| `/wordle-guesser/`, `/wordle-unlimited-solver/`, `/{3,4,6,7}-letter-wordle-solver/` | `src/pages/solvers.mjs` | Same solver widget with different settings |
| `/5-letter-word-finder/`, `/wordle-dictionary/`, `/wordle-word-list/`, `/wordle-unscrambler/` | `src/pages/word-tools.mjs` | |
| `/5-letter-words/…` (starting-with, ending-in, containing × A–Z) | `src/pages/word-lists.mjs` | Pages with no words are skipped; pages with fewer than 10 are `noindex` |
| `/guides/…` | `src/pages/guides.mjs` | Starting-word and filler-word guides are computed from the word lists |
| `/about/`, `/contact/`, `/privacy/`, `/terms/`, `/disclaimer/` | `src/pages/site.mjs` | |

Every page links back to the homepage with the anchor text "Wordle Helper". The test suite enforces this. Every page also carries the "not affiliated with The New York Times" disclaimer in the footer. The build writes `sitemap.xml`, `robots.txt`, canonical tags, Open Graph tags and JSON-LD (WebApplication, FAQPage, BreadcrumbList, Article).

Other code:

- `src/assets/js/engine.js`: scoring (with Wordle's duplicate-letter rules), filtering, ranking and best-guess entropy. It's shared by the browser and the build.
- `src/assets/js/*.js`: the browser tools (solver, finder, dictionary, unscrambler, daily notice).
- `src/lib/layout.mjs`: page shell, header/footer, FAQ, breadcrumbs and shared components.
- `src/lib/site.mjs`: domain, contact email, navigation and footer links.

## Daily hints workflow

`/wordle-hint-today/` is one permanent URL. Each day:

1. Add the day's answer: `npm run add-answer -- YYYY-MM-DD answer "optional clue"`. The clue becomes the last hint before the answer reveal. Other hints (vowels, repeated letters, rare letters, first and last letter) are generated automatically.
2. Rebuild and deploy.

The build only shows entries dated on or before the build date (`BUILD_DATE` env var, default today in UTC). That means you can schedule entries ahead and they stay hidden until their day. Once a newer puzzle is published, the previous day's answer moves into `/wordle-answers/`. A small script on the hint page warns visitors whose local date is on a different puzzle, since Wordle resets at local midnight.

`data/daily.json` starts empty. No answers are bundled. Because the hint page changes daily, set up a daily rebuild on your host (a scheduled deploy hook or CI cron) after you add the entry.

## Word lists

The lists in `data/words/` are generated from [SCOWL](http://wordlist.aspell.net/) via the `wordlist-english` package:

- `N-answers.txt`: common words (SCOWL levels up to 50), minus plurals, past tenses and the words in `data/not-answers.txt`.
- `N-valid.txt`: everything up to SCOWL level 70.
- `data/blocklist.txt`: slurs removed from every list.

They are **not** the official NYT lists. Regenerate them with `npm install && npm run wordlists`, which also recomputes `data/openers.json` and `data/second-words.json`. SCOWL's license requires its copyright notice to accompany the lists; it is in `data/words/LICENSE-SCOWL.txt` and is published at `/LICENSE-SCOWL.txt`.

## Deploying

Any static host works (Cloudflare Pages, Netlify, Vercel, GitHub Pages, S3). Use build command `npm run build` and output directory `dist`. The host should serve `404.html` for missing pages; most do automatically.

## Before launch

- Set up the `hello@wordlehelp.co` mailbox (or change `SITE.email` in `src/lib/site.mjs`).
- If you add analytics or ads, update `/privacy/` first.
- Submit `https://wordlehelp.co/sitemap.xml` to Google Search Console.
